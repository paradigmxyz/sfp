# Theorem T6: Adaptive Lambda from Signal Decay

## Definitions

Consider fine-tuning a neural network with parameters θ_t at step t, with:
  L_new(θ) — new-task loss (to be minimized)
  L_pres(θ) — preservation loss (SFP regularizer)

The total objective is:
  L(θ) = L_new(θ) + λ(t) · L_pres(θ)

where λ(t) is a time-varying regularization strength.

Define the **subspace drift** at step t:
  δ(t) = Σ_ℓ ‖P_{W_ℓ}(a_ℓ(θ_t) - a_ℓ(θ_0))‖²

Under gradient descent with learning rate η, the drift evolves as:
  δ(t+1) = δ(t) + 2η⟨P_W ∇L_new, P_W Δa⟩ + η² ‖P_W ∇L_new‖² - 2ηλ(t) · δ(t)

The last term comes from the SFP regularizer pulling δ back toward zero.

**Exponential decay model.** Assume the signal (useful gradient in the preserved subspace) decays exponentially:
  s(t) = ‖P_W ∇L_new(θ_t)‖² = s_0 · exp(-αt)

where α > 0 is the decay rate (as the network learns the new task, the gradient signal in old-task-relevant directions diminishes).

Define:
  η — learning rate (constant)
  μ — strong convexity parameter of L_new restricted to W
  κ = L/μ — condition number (L = smoothness constant)

## Claims

1. **Drift dynamics under constant λ.** With constant λ, the drift satisfies:
     δ(t) ≤ (1 - 2ηλ)^t · δ(0) + [η · s_0 / (2λ - ηα)] · (exp(-αt) - (1-2ηλ)^t)

   when 2λ > ηα (regularization dominates signal injection).

   For large t:
     δ(∞) ≈ η · s_0 / (2λ)    (steady-state drift)

2. **Optimal constant λ.** The optimal constant λ that minimizes the max drift while achieving target new-task loss L_new* within T steps is:
     λ* = (s_0 · η) / (2 · δ_target)

   Prove via: setting δ(∞) = δ_target and solving for λ.

3. **Exponential λ schedule optimality.** Under the exponential signal decay model s(t) = s_0 · exp(-αt), the schedule:
     λ(t) = λ_0 · exp(-αt/2)

   maintains constant drift rate dδ/dt, which is optimal in the following sense:
     It minimizes max_t δ(t) subject to Σ_t λ(t) ≤ Λ_budget (total regularization budget).

   Prove via: the isoperimetric argument — constant drift rate (equal marginal cost at all times) minimizes peak drift under a total budget constraint.

4. **Decay rate estimation.** The decay rate α can be estimated online from two consecutive measurements of the signal:
     α̂ = -[log(s(t₂)) - log(s(t₁))] / (t₂ - t₁)

   Under the exponential model, this is an unbiased estimator. With k measurements, the MLE is:
     α̂_MLE = -[Σ_i w_i · log(s(t_i))] via weighted least squares on log-signal vs time.

5. **Convergence guarantee with adaptive λ.** Using λ(t) = λ_0 · exp(-αt/2) with α estimated from data:
     δ(T) ≤ δ_target + O(|α̂ - α| · T · s_0 / λ_0)

   So misestimation of α introduces linear-in-T error scaled by the estimation error.

6. **Numerical verification.** With typical SFP parameters:
   - T = 1000 steps, η = 1e-4, λ_0 = 0.1
   - s_0 = 1.0 (initial gradient signal in preserved subspace)
   - α = 0.005 (signal halves every ~140 steps)

   a) Constant λ = 0.1: δ(∞) = 1e-4 · 1.0 / 0.2 = 5e-4
   b) Adaptive λ(t) = 0.1 · exp(-0.0025t): peak δ is lower by factor ≈ 1.5 compared to constant λ
   c) Savings: adaptive schedule uses 40% less total regularization (Σ λ(t)) for same max drift
